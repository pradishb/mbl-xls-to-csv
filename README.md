# mbl-xls-to-csv

Convert MBL bank XLS statement to CSV for homebank

## Installation

You can install the package via pip:

```
pip install mbl-xls-to-csv
```

## Usage

```
mbl-xls-to-csv statement_1726666564255.xls
```
